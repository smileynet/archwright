# Actionable Without Literacy

## Statement

A developer whose check run flagged the project knows what to do — fix the code, revisit a design rule, or flag a broken check — without archwright literacy.

## Who Feels It

Developer

## Evidence

- `discovery:design-system#D002`: "we want to ux to focus on non-jargon, low cognitive-complexity reporting that is actionable to users without requiring them to understand archwright specifically"
- `discovery:design-system (Jobs J1)`: "they know the action (fix code / revisit a design rule / check is broken) without reading archwright docs"
