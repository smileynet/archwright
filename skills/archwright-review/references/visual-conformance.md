# Visual Conformance — Method Reference (ticket 044/045)

Single authority for the blind question-asking method. The battery file
(`tools/report/visual-battery.md`) holds project-specific questions; ticket 044 is the
closed decision record with the research citations. Load-bearing assumptions are
locally measured (ticket 047, below) — re-run the probes on model upgrades:
`tools/report/probes/` (gen_seeded.py → capture.mjs → blind subagent asks →
score_s3.py / score_s1s2.py).

## The loop

1. **Generate** the report bundle(s) — at least two postures when judging
   posture-dependent decisions.
2. **Capture**: `node tools/report/capture.mjs <report.html> -o <dir>` — deterministic
   recipe, per-section crops pre-resized (≤1568px long edge, ≥200px floor via
   context-padding), light + dark, `manifest.json` lists regions. Missing playwright
   → loud exit 2 with install instructions.
3. **Battery**: derive ≥1 neutral question per active D-anchor (conservation both
   directions; undecidable-by-looking anchors get a not-visually-checkable entry).
4. **Blind answering**: subagent fan-out, fresh session per section, 1–2 labeled
   images per stage, unprimed description FIRST, answers → files. The answerer never
   sees decisions, wireframes, or expectations.
5. **Judge** in the main session (which holds the ledger): join answers to anchors,
   classify match / mismatch / unclear, emit a triage table.
6. **Non-vacuity**: a deliberately-broken variant must flip the blind answers in the
   broken dimensions — this probes the questions, not just the page.

## Hard rules (each has an incident behind it)

- **Questions never contain the expected answer.** Stated expectations shift VQA
  answers toward the prompt-favored option in both directions (published: 12–42pt
  accuracy drops). Local S1 probe (2026-07-23) measured a 0pt delta at n=5 false
  leads — the collapse did NOT reproduce on clean seeded pages, but n is far too
  small to license leading questions and the published risk is asymmetric: blindness
  costs nothing, so the rule stands as cheap insurance.
- **Verify blind claims semantically, never by proxy.** The 044 judge "refuted" a
  true no-transitions finding by counting SVG paths — paths are box outlines, not
  edges. Test the claim itself (are there arrows between states?), not a correlate.
- **Absence claims are low-confidence by construction** — one hallucinated absence
  and one true absence appeared in the same run (044, field page); mechanical
  verification at judge time is mandatory before reporting either. Local S2 probe
  (2026-07-23): false-absence 0/5, false-presence 0/5 on seeded pages — well under
  the 20% drop-absences-entirely threshold, so absences STAY reportable (policy
  confirmed, not amended). The seeded pages are cleaner than field pages; the 044
  field hallucination is why mechanical verification stays mandatory despite the
  0% measured rate.
- **Findings ruled by ratified decision text route fix-implementation — no HITL.**
  Triage means joining a finding to its D-anchor; if the decision text rules
  directly, fix it (ADR-0010 routing). Escalate only genuine ambiguity or suspected
  legitimate divergence. (Incident: F1–F3 were needlessly escalated, 2026-07-22.)
- **Padded crops leak neighboring context** — region isolation is soft; judge
  region-scoped claims accordingly.
- **Interactive states are unaskable from static capture** (response bar, folds) —
  mark unclear, don't guess; scripted-interaction capture is future work.

## Measured floor (local, 2026-07-23 — ticket 047 P0 probes)

Model: claude-fable-5 via kiro-cli subagent dispatch (the battery's real path).
Ground truth: seeded report pages generated by `tools/report/probes/gen_seeded.py`
at the capture harness's real crop geometry (1280px sections, 200px padded floors).
All numbers are small-n local measurements, not guarantees — re-run on model
upgrades and treat regressions as method-blocking.

| Probe | Result | n |
|-------|--------|---|
| S3 OCR fidelity, light | 20/20 strings verbatim (100%) | 20 strings, 6 crops |
| S3 OCR fidelity, dark | 20/20 strings verbatim (100%) | 20 strings, 6 crops |
| S1 neutral accuracy | 10/10 | 10 questions |
| S1 false-lead exposure | 5/5 refuted (0pt delta vs neutral) | 5 false leads |
| S1 true-lead confirmation | 5/5 confirmed | 5 true leads |

Implications: the describe-pass meets its ≥95% floor with margin in BOTH color
schemes (dark had never been analyzed before this run); rule IDs, counts, glyphs,
and ★ survive transcription exactly. The prior absence policy rested on n=2 field
observations — it now also rests on n=10 seeded (and says so). Scoring was
mechanical where possible: `score_s3.py` (verbatim containment),
`score_s1s2.py` (truth-key matching; 20/20 auto-resolved, zero manual overrides).
